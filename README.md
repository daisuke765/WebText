# WebText Tetris

Next.js と React Hooks を使ったシンプルなテトリスのサンプルです。
学習教材として、`useState` や `useEffect` の利用方法を理解できるように構成されています。

## 実行方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてゲームをプレイできます。

## ファイル構成

- `components/Tetris.js` — テトリスのゲームロジックと描画
- `pages/index.js` — トップページ

依存パッケージは `package.json` を参照してください。
